# Learning Centre Sprint L2L — Certification & Masterclass Academy

The Learning Centre's own capstone academy — a recommended study sequence, an honest account of what "certification" means on this platform (self-directed progress, never an issued credential), and three synthesis masterclasses combining every prior academy's real, already-taught features into one coherent professional practice per engine.

## 1. Certification Capability Map

Before writing any content, the platform's own certification, progress, and Learning Centre architecture was inspected directly (targeted source reading, since this sprint is self-referential about content already built across this session's own prior L1–L2K sprints — direct investigation was more efficient and equally thorough than dispatching subagents for content this deeply familiar).

### Fully implemented capabilities

- **Self-reported lesson completion** (`recordViewed`/`recordCompleted` in `learningProgress.ts`, upserting into a single `learning_progress` table keyed on `(userId, itemType, itemKey)`), driven entirely by the plain "Mark Complete" button in `LessonRenderer.tsx` — a self-reported user action, not a graded assessment.
- **Live, computed per-path completion percentages** (`pathCompletion`, computed in `getLearningProgress()` as `completedLessonKeys.length / topicsTotal` per path) — real and genuinely live, not cached or estimated.
- **Bookmarks** (`setBookmarked`), independent of completion, spanning every item type.
- **Knowledge Checks** (`KnowledgeCheck.tsx`) — explicitly, by the component's own design comment, "ungraded and ungated": once every question has been answered at least once (right or wrong; a "Try again" re-answer never un-completes it), the check is marked complete exactly once. A running "X of N correct on first try" score is shown for the learner's own benefit only and never blocks or delays completion.
- **Two genuinely, independently scored practice quizzes** — the Greeks Quiz and the Value Investing Quiz (`greeksQuizResultsTable`/`valueQuizResultsTable`, aggregated via `computeQuizProgress()`), each storing a real percent-correct score per attempt.

### Partially implemented / disclosed-scope capabilities

- The two real scored quizzes above are **never checked anywhere** to gate lesson completion, path completion, or any certification status — they are entirely standalone practice tools, tracked independently of everything else.

### Educational-only concepts (no platform feature exists)

- **No certification or credentialing engine exists anywhere in this codebase** — confirmed via targeted, broad searches (`grep -rli "certif\|achievement\|masterclass"`) across both `artifacts/api-server/src` and `artifacts/ravish-trading/src`: no certificate issuance, no PDF export, no badge/achievement system beyond generic, unrelated UI `Badge` components, and no pass/fail gate tying any quiz score or lesson completion to an official "certified" status.
- No learning-specific reminder, notification, or calendar-scheduling feature exists — the same "cadence is a descriptive tag, never a scheduler" honesty already established for the Portfolio Workspace's Workflow Center (Sprint L2K) applies identically to any suggested study cadence in this academy's own content.
- No coded prerequisite/dependency-locking system exists between paths or topics — `getLearningPath()`/`getLearningTopic()` are simple key lookups with zero gating logic; every path and topic is reachable directly by URL regardless of progress elsewhere.

### Components reused

- The shared `LessonRenderer.tsx` component, the extracted `QuizCard`-based `KnowledgeCheck.tsx` component, bookmark support, progress tracking, and glossary linking — all reused completely unmodified, exactly as every prior L2-series sprint's own content did.
- The Learning Centre home page (`/learn`, `LearningCentre.tsx`), which already computes and displays real, live `pathCompletion` percentages, a "weakest paths" panel (paths under 50% complete), recent history, and bookmarks — the genuine anchor point this academy's own Learning Roadmap and Continuous Professional Development lessons point learners back to.

### Areas requiring disclosure as educational guidance

- Every reference to "certification" across all six new topics is explicit, self-directed learning discipline — stated plainly, most directly in the Becoming Platform Certified lesson, that no certificate or credential is ever issued by this platform.
- The pre-existing, architecturally separate **Delta Masterclass** page (`/learn/delta`, served by `coach.ts`'s `deltaMasterclass()` function via `GET /coach/learn/delta`, a `LearnContent`-shaped lesson distinct from this file's own `LearningPath`/`LearningTopic` system) is a different, older feature from this new academy's three "Masterclass"-titled `LearningTopic` entries. The two are never conflated in this sprint's own content or navigation — a disambiguation discipline matching the same precedent already established for "Trading AI Coach vs. AI Trade Coach" (Sprint L2J) and "4 executable vs. 9 educational strategies" (Sprint L2K).
- Institutional Mentor genuinely has no free-form chat/prompt interface (confirmed in Sprint L2J's own investigation and re-confirmed here) — every "Institutional Mentor:" line in this academy's `aiCoachPrompts` arrays is phrased consistently with genuine AI Coach prompts for stylistic uniformity, but each is accompanied by explicit body or prompt text clarifying it means visiting Institutional Mentor's own page directly, never typing a free-form question.
